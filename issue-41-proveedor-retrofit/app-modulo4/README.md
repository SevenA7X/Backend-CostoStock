# app-modulo4 · Cambios de la app Android del Módulo 4

Esta carpeta **no es la app completa**: contiene solo los archivos nuevos o modificados de la app CostoStock, separados por issue. Cada subcarpeta tiene su propio README.

| Carpeta | Issue |
|---|---|
| `issue-41-proveedor-retrofit/` | #41 · ProveedorViewModel envía el lote con foto vía Retrofit (RF-05) y métricas desde el backend (RF-07) |
| `issue-42-api-externa/` | #42 · Retrofit separado consumiendo la API pública Open-Meteo + vista `ClimaScreen` |

Para aplicarlos, se copia el contenido de `issue-XX/app/` sobre la carpeta `app/` del proyecto Android y se ejecuta en Android Studio.
